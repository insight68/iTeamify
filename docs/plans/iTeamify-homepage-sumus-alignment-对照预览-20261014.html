#问题选项与影响
D1 参照到什么程度？ A 只借调性（字体 + 底色 + 去描边，区块结构不动）→ 改动最小、零内容风险，但 11 个区块的冗余还在，页面仍偏长。
B 调性 + 结构一起收敛（上方 D 区方案，11→8）→ 效果最好，需要改 i18n/{en,zh}.ts 的 home 结构并同步 resources-types.ts，回归面涉及中英两套字典与 3 个测试。
C 只挑 3 个高杠杆动作（衬线 H1/H2、FAQ 与最终 CTA 改版、去描边）→ 半天量级，能拿走近 60% 的观感收益。
D2 主 CTA 用品牌蓝还是墨色？ 蓝 #165de5：保住品牌识别，与 header / 服务页一致。
墨 #102c46：更接近 sumus 的黑白调，整页彩度归零，但首页 CTA 会和服务页 CTA 不一致。
D3 首屏要不要换真实产品截图？ 现在是纯 CSS 复刻的三栏看板，看得出是"设计稿"，说服力弱于真截图（sumus 用了 22 张真图）。
换真图需要你提供工作区实拍（截图需脱敏），或授权我用种子数据起一套本地环境自拍。
D4 首页要不要加定价？ sumus 把 pricing 放在 FAQ 之前，是转化的主锚点；我们首页目前没有任何价格信息。
但我们主力是 AccioWork 交付服务而不是 SaaS 订阅，首页报价口径需要你给（否则我不写数字）。
D5 改动范围要不要扩到服务页？ H1/H2 字号与字重目前首页、服务页、服务详情页三套（58/500、clamp(33,3.4vw,50)/700、clamp(40,5.2vw,70)/450）。 只改首页会留下"首页衬线、服务页粗黑"的新断层；一起收口则需要动 service-marketing.css（全站服务页共用）。
证据来自本地 next dev（端口 3466）与 sumus.im 的 1440×900 / 390×844 双视口实拍。 完整实测数据（区块高度、字号集合、边框元素计数、溢出检查）见方案 md。
